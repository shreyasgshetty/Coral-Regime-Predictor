# Coral-Regime-Predictor


This repository contains a machine learning project that predicts coral bleaching severity based on environmental and site-specific features. The goal is to classify reef sites into **Low**, **Medium**, or **High** bleaching categories using Logistic Regression, Support Vector Machines (SVM), and Random Forest.

---

## 📝 Problem Statement

Coral reefs are highly sensitive to environmental changes, particularly temperature fluctuations. Accurate prediction of bleaching severity can help conservation efforts. This project uses historical coral survey data and environmental parameters to predict the bleaching class of coral reef sites.
